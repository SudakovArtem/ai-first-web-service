# AI Bug Triage

## Контекст

- Учебный HTTP-сервис для первичного разбора веб-багов. Текущий этап принимает, валидирует и показывает тикеты в памяти.
- Точка входа — `src/server.ts`. Контракт API и команды запуска описаны в `README.md`.

## Работа над задачами

- Перед правками проверь текущий контракт и сформулируй проверяемый результат. Для задачи из нескольких шагов составь короткий план.
- Выбирай минимальное решение по требованиям задачи. Сохраняй поведение существующих маршрутов, если задача явно его не меняет.
- Ограничивай изменения нужными файлами. При изменении API или команд обновляй соответствующий пример в `README.md`.
- Для поиска используй `rg`. Независимые проверки можно выполнить параллельно.
- Для демонстраций и запросов к LLM используй синтетические тикеты. Храни ключи в окружении и исключай их из логов и Git.
- Перед удалением данных, `DROP` в БД или принудительной отправкой Git-ветки запрашивай подтверждение.

## Команды и проверка

- `npm ci` — установка зависимостей из lockfile.
- `npm start` — локальный запуск API.
- `npm run check` — линтинг и проверка типов после правок.
- При изменениях в HTTP-слое прогони затронутый сценарий из `README.md` и сообщи фактический результат.
